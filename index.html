Puente H para 2 Motores DC

Control de velocidad (PWM) y sentido de giro con transistores y diodos discretos.

Esquemático completo · motor

Rojo: corriente de potencia. Azul: corriente de excitación. Para seguir cada ciclo del PWM baja la velocidad a 0,01× o menos.

Código de ejemplo para el ESP32

Arduino-ESP32 3.x (ledcAttach / ledcWrite). Se actualiza con la frecuencia PWM y el tiempo muerto.

El modo complementario con tiempo muerto por hardware requiere el periférico MCPWM del ESP32; LEDC no lo genera.
